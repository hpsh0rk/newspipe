# 原始版本观察与本地关联预览验收

## 本阶段范围

在现有消息源基础边界上增加前瞻性的原始版本台账、保守本地提案与紧凑只读预览。
默认关闭，保存观察设置后等下一次真实采集激活；不依赖 Horizon，不接入 MCP/Skill，
不增加新信源，不调用差异比较模型，不自动合并或抑制通知，不迁移/重发已有队列与历史，不改收藏。

职责链：`pipeline` 在采集后、过滤和加工前交给 `story_capture`；
`observations` 纯函数保存完整版本指纹与原始材料，`story_matching` 只提本地候选；
`Store` 持有私有 SQLite 路径，`story_state` 只负责事务与读快照；
`config` 是设置 schema/校验来源，页面动作只翻译到同一 CLI handler，`webstories` 只读展示。

## 验收覆盖

- 同一原生 ID 已通知后变化：保存不可变新版本，不改 pushed、旧批次/回调、队列或收藏，不历史重发。
- 计数/时间戳变化与重试：不制造内容版本；完整原始 JSON 首次落盘后不覆盖。
- 副本提案：显式文章类型、完整正文声明、至少 160 个非空白字符、标题/正文/事实/引用一致；仍不合并。
- 共享链接但评论不同、社交/未知类型或弱标题：不能升级为确定副本；词面相似只做候选。
- 同 ID 新材料：标未分类变化。只有完整证据可列具体字段，截断快照只证明来源材料改变。
- 晚到内容按采集顺序保留，发布时间未知不伪造；同 ID 前驱不受跨源回看窗口限制。
- 旧原文缺失/生成/截断：显式不确定迁移基线，不将首次重抓判成重复或进展。
- off/observe 切换、ABA、并发历史变化、重启：独立激活 ID/前沿，慢任务保存原文但不恢复旧设置或保存过期提案。
- 历史缺失、锁定、损坏、写中断：可区分，无读取修复；观察失败保留待处理但不推进新内容游标。
- 冻结投递恢复与通知：不采集/重比较，观察故障不阻断旧冻结载荷的恢复；关闭时旧历史故障只警告。
- CLI 分页、信封、退出码、未知详情：版本与回执游标分别验证，非法分页与存储失败不伪装成空结果。
- 页面原文/URL/XSS/敏感头：允许字段、有界文本、脱敏链接不可点击；读取前后所有文件字节不变。
- 设置弹窗与 no-JS PRG：actions/Origin/token/hash 门禁，校验不应用，错误和 dry-run 保留草稿，保存不激活历史。
- Chromium/WebKit、360/1440 宽度、键盘打开/关闭/焦点、分页/详情/旧条目返回及损坏警告的离线验收。

浏览器 fixture 仅使用临时目录和合成数据，浏览器请求限定同源；真实凭据、网络、模型、
发卡与原后端群查询均被拒绝。模拟采集与群目录明确区分，不作真实信源可用性声明。
合成 `doctor --json` 使用凭据可用性桩，不读取真实密钥，不发探测卡；卡片元素预算不变。

## 检索与展示限制

保存范围默认回看 14 天（1..90）、每条 5 个候选（1..20）、扫描 500 条（50..2000）。
本地 Jaccard 阈值 0.35 只用于召回；最多使用 20,000 字符、256 个词/中文双字项。
窗口基于最后采集时间，原发布时间单独保留。缩小窗口或达到扫描上限会漏召回，不代表无关。
读取已保存回执，不按新设置重算。页面每页最多 5 次回执、每次前 5 个提案/版本，
最多 40 次去重标题查找；完整有界回执可用 `stories preview --json` 分页读取（limit 1..100）。
公共正文/事实各限 20,000 字符，标题 500 字符、引用最多 20 个；截断/脱敏均显式标注。

原始 JSON 私有完整保留，历史不自动删除，存储会持续增长。部署侧需做备份/容量监控，
本阶段没有自动清理或重建工具，不能删除历史来“修复”。
私有目录/数据库写入权限为 0700/0600，SQLite 日志随数据库保持所属用户权限；读路径不修改权限。
敏感事实键递归脱敏，过大/深层或无法安全解析的事实明确省略，不展示未经结构化脱敏的截断 JSON。
当前多数旧适配器还未声明完整文章类型/正文；因此确定副本能力有限，不能以候选准确率代替事实验证。
观察打开且本地记录失败会延迟新完成，但成功内容保留；这是耐久性故障，不是通知去重回执。
